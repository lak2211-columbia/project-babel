# `data/` — Project Babel corpus

Everything the observatory ingests, parses, and analyzes lives here. Checked in so the project is reproducible from a fresh clone without hitting any external service.

For the project overview, see the [root README](../README.md). For how these files are produced, see [`../services/pipeline/README.md`](../services/pipeline/README.md).

---

## Layout

```
data/
├── sources/                   Hand-curated seed manifests per jurisdiction.
│                              Authoritative list of tracked documents.
│
├── taxonomies/                Canonical label vocabulary
│                              (framing, requirements, enforcement, binding).
│                              Validated by `make taxonomy`.
│
├── discovery/                 Output of discovery scans — candidate URLs
│                              pulled from configured official portals.
│                              Cleared and regenerated by `make discover`.
│
├── source_tracking/
│   ├── source_inventory.json            Full source inventory
│   ├── candidate_enrichment/            Per-URL enrichment cache
│   │                                    (dates, languages, issuing bodies)
│   └── audit_snapshots/                 Quality audit artifacts
│
├── retrieval/                 Fetch run logs and retry history.
│
├── manual_imports/            Records for documents imported via
│                              `observatory import-local-document`
│                              (used when an official portal is unreachable).
│
├── raw/                       Raw fetched artifacts.
│   └── <jurisdiction>/
│       └── <document_id>/
│           ├── <artifact>               PDF / HTML / DOCX / HWPX / JSON
│           ├── metadata.json            Canonical URL, publication date,
│           │                            language, issuing body, content-type
│           └── retrieval_log.json       Timestamps, content sha256, retries
│
├── parsed/                    Normalized text extracted from raw/.
│   └── <jurisdiction>/
│       └── <document_id>/
│           └── normalized.json          title, language, plain_text,
│                                        sections[], warnings[], parser_version
│
└── analysis/                  Claude Sonnet 4.6 structured extraction.
    ├── <jurisdiction>/
    │   └── <document_id>/
    │       ├── document_analysis.json   Authoritative combined output
    │       ├── policy_extraction.json   Materialized policy subset
    │       ├── risk_framing.json        Materialized framing subset
    │       ├── policy_response.raw.json Raw Anthropic envelope
    │       └── framing_response.raw.json
    └── jurisdictions/
        └── <jurisdiction>/
            └── jurisdiction_input_digest.json
                                         Aggregated feed for the
                                         per-country narrative pass
```

## Scope

Five jurisdictions are currently tracked:

- **`united_states`** — federal legislation, executive orders, NIST guidance, congressional mandates, agency rulemaking
- **`european_union`** — the AI Act, GPAI code of practice, Commission guidelines, standardisation work, the AI Pact
- **`south_korea`** — the AI Basic Act and enforcement decrees, MOGAHA/KISDI guidelines, industrial strategy papers
- **`japan`** — METI guidance, Cabinet Office strategy, Hiroshima AI Process code, expert-panel reports
- **`china`** — CAC generative-AI measures, algorithmic recommendation rules, national AI supervision regulations

Directory names use snake_case (`united_states`, `european_union`, `south_korea`) to match the `JurisdictionKey` enum used throughout the Python pipeline and the TypeScript lib.

## Provenance

Everything under `raw/` is a copy of a publicly available government publication. Each document's `metadata.json` records the canonical URL it was fetched from, and each `retrieval_log.json` records the timestamp, HTTP status, and SHA-256 content hash of the artifact that produced the parsed and analyzed output. Nothing in this repository is behind a paywall; nothing is scraped from non-official sources.

If you want to verify provenance for any document:

1. Find it at `analysis/<jurisdiction>/<document_id>/` or `parsed/<jurisdiction>/<document_id>/`.
2. Look at `raw/<jurisdiction>/<document_id>/metadata.json` for the `canonical_url`.
3. Cross-check against the original publication at the canonical URL.

For documents fetched through the manual import path (when a portal is unreachable), `retrieval_log.json` records `source: "manual_import"` and the local file path rather than a URL.

## Licensing notes

The raw documents under `data/raw/` are copies of **public government publications** retained for pipeline reproducibility. Redistribution varies by jurisdiction, but all sources are public records:

| Jurisdiction | Typical licensing regime for tracked documents |
|---|---|
| **United States** | Federal government works are in the public domain under 17 U.S.C. § 105. Redistribution without restriction. |
| **European Union** | Commission Decision 2011/833/EU permits reuse of most Commission documents, subject to attribution. Council and Parliament materials are generally open access. |
| **United Kingdom** (if added) | Crown Copyright under the Open Government Licence — redistribution with attribution permitted. |
| **Japan** | METI, Cabinet Office, and similar agencies typically permit reuse with attribution under open-government policies. |
| **South Korea** | KOGL (Korea Open Government License) permits reuse with attribution. |
| **China** | No formal open license. The tracked documents are administrative and legal texts, which in most jurisdictions are not protected as creative works. |

**Authoritative sources always remain the issuing government.** The canonical URL in each `metadata.json` is the source of truth for any document's current version; this repository preserves only the snapshot at the time of retrieval.

If you are a rights-holder and have a concern about a specific document retained here, open an issue on the repository and we'll either redact the artifact, replace it with a link-only reference, or work out an appropriate takedown procedure.

## Regenerating the corpus

From the repository root:

```bash
make refresh           # discover + fetch + coverage report
make parse             # normalize raw artifacts into parsed/
make analyze           # run Claude Sonnet 4.6 on parsed documents (requires ANTHROPIC_API_KEY)
```

The content is idempotent: re-running `fetch` only re-downloads documents whose SHA-256 has changed upstream; re-running `parse` and `analyze` only processes downstream of changed inputs.
